# Zoom Gelato — concept website

A responsive static concept site for **Zoom Gelato in Annaba, Algeria**.

## What is included

- Red/white-first brand system using `#cd2920`, `#fff8f6`, `#fec30d`, `#2596be`, and `#d77a75`
- Custom food illustrations for pancakes, waffles, and gelato
- Scroll-triggered reveals and rolling food motion
- Searchable/filterable menu based on the supplied menu artwork
- Interactive “Build your Sundae” demo with a live total
- Mobile navigation and responsive layouts
- Reduced-motion support
- Direct links to Zoom Gelato’s Instagram, Facebook, and Google Maps
- No framework or build step: just HTML, CSS, JS, and SVG

## Preview locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publishing

This repository is ready for GitHub Pages. Set the Pages source to the `main` branch / repository root in GitHub settings.

> Demo note: menu availability and prices should be confirmed with Zoom Gelato before a production launch.
